重跑時先另開終端機（4174 需空閒）：

```powershell
node tools/upgrade-server.js
```

再用已開啟的 Playwright session 執行：

```powershell
npx --yes --package @playwright/cli playwright-cli -s=bus-review run-code --filename=tests/browser-upgrade.js
```

此 server 僅限 localhost，專供驗收；結束後按 Ctrl+C 關閉。它由 Git 基準讀舊版檔案，未讀取備份目錄。
