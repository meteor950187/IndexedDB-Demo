## 驗證範圍與限制

- 真實瀏覽器驗證為 Chromium；未實機測試 Safari／Firefox。
- 沒有部署遠端 CDN，沒有量測 CDN 命中率。HTTP cache 由官方 headers 與瀏覽器決定。
- 官方各檔獨立更新，僅能保證下載後本機整批提交，無法保證上游三檔在同一發布瞬間。
- 官方資料可能包含暫停站牌或主路線合併的支線；此為路線資料展示，非即時營運或轉乘建議。
- 瀏覽器儲存空間回收及使用者清除網站資料會移除離線資料。
